1. GESTION DU CHEMIN DU FICHIER IR (state)
------------------------------------------
Le chemin n'est PAS un parametre (un parametre DPF est un float) : c'est un state.
Decision prise : state "ir_path", avec le flag kStateIsFilenamePath.

Je voudrais :
 a) Le code actuel de initState() (ou ce qu'il faut ajouter) pour declarer
    le state "ir_path" avec kStateIsFilenamePath.
 b) Le code de setState(key, value) et de getState(key) pour "ir_path".
 c) Comment le chargement de l'IR est lance quand le state change :
    - thread dedie (jamais sur le thread audio) ?
    - que se passe-t-il si un nouveau chemin arrive pendant un chargement ?
    - le chemin est-il relatif au projet ou absolu ?
 d) Comment pIRStatus (No IR / Loading / Loaded / Error) et pIRLengthMs
    sont mis a jour pendant et apres le chargement.
 e) Formats de fichiers acceptes (wav seul ? flac ? multicanal ? frequences
    d'echantillonnage differentes de celle de l'hote : reechantillonnage ?).

Cote UI j'appellerai : setState("ir_path", chemin), et requestStateFile()
pour ouvrir le selecteur de fichier natif.


2. DONNEES DE L'IR A ENVOYER A L'UI (affichage)
-----------------------------------------------
L'UI doit dessiner l'IR APRES transformations (trim, stretch, attack, decay,
reverse, normalisation, mode d'entree), en deux vues :
 - WAVE : enveloppe temporelle (crete min/max par colonne, ~500-1000 points)
 - SPECTRUM : spectre de l'IR (FFT, magnitude en dB, axe frequentiel log,
   ~200-300 points entre 20 Hz et 20 kHz)

Questions :
 a) Ces donnees sont-elles (ou peuvent-elles etre) calculees cote DSP/thread
    de chargement, apres chaque reconstruction de l'IR ?
 b) Comment les transmettre a l'UI ? Proposition a discuter :
    state en lecture seule (ex. "ir_display", tableau de floats encode),
    ou autre mecanisme. Quelle taille maximale raisonnable ?
 c) Comment l'UI sait-elle qu'une nouvelle version des donnees est prete
    (changement de pIRStatus vers Loaded, compteur de version, ...) ?
 d) Longueur et duree reelle de l'IR apres transformations (pIRLengthMs suffit ?).
